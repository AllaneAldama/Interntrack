# InternTrack
Web-Based Internship/OJT Monitoring and Management System

Stack:
- PHP (procedural)
- MySQL
- HTML/CSS
- JavaScript

Starter implementation:
- Role-based login
- Student, Coordinator, Supervisor, Admin roles
- Dashboard routing
- Core OJT database structure
- Basic student internship profile
- Basic attendance, requirements, reports, and evaluation tables

## Setup
1. Copy the `interntrack` folder into `C:\xampp\htdocs\`.
2. Start Apache and MySQL in XAMPP.
3. Open phpMyAdmin and import `database/interntrack.sql`.
4. Visit `http://localhost/interntrack/`.
5. Demo accounts are included in the SQL file. Passwords are `password123`.

This is the first development baseline. Final-term API integrations and deeper CRUD workflows can be added without changing the overall project structure.
